# NIMbus UI fixes

This version keeps the existing Starry Glass design and fixes the two issues shown in the screenshots:

1. **Dashboard analytics cards:** the Fault Distribution and Threat Severity cards now use safe grid/flex sizing so charts and legends are not clipped by the card width. The cards can expand naturally instead of being cut by overflow.
2. **My Work / Work & Performance:** the four work counters are now shown in a translucent tabular Work Summary with rows for Total Work, Completed, Ongoing, and Pending / Blocked.

No backend/API changes were made.
